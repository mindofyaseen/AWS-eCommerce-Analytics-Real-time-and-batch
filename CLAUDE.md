# Project: eCommerce Analytics Platform on AWS

## Overview
Building an end-to-end eCommerce analytics platform on AWS with two pipelines, based on a well-known AWS "Build an Analytical Platform for eCommerce" reference architecture (ProjectPro / AWS blog style project). This is a portfolio/learning project, not production.

**Two pipelines:**
1. **Batch pipeline** — historical analytics (unique visitors/day, cart abandonment, top categories per hour/weekday, brand marketing insights) via Firehose → S3 → Glue → Athena → QuickSight
2. **Real-time pipeline** — DDoS/bot detection via Kinesis Data Streams → Apache Flink → Kinesis Data Streams → Lambda → DynamoDB / CloudWatch / SNS

## Flink SQL (Zeppelin notebook — must be re-run each session since notebook state resets on Stop)
**3 cells to run in Zeppelin each session — Zeppelin REST API is browser-only, can't be automated via CLI:**

**Cell 1 — Source Table:**
```sql
%flink.ssql
CREATE TABLE ecomm_events (
    event_time VARCHAR,
    event_type VARCHAR,
    product_id VARCHAR,
    category_id VARCHAR,
    category_code VARCHAR,
    brand VARCHAR,
    price DOUBLE,
    user_id VARCHAR,
    user_session VARCHAR,
    event_arrival_time AS PROCTIME()
)
WITH (
    'connector' = 'kinesis',
    'stream' = 'ecomm-events-stream',
    'aws.region' = 'us-east-1',
    'scan.stream.initpos' = 'LATEST',
    'format' = 'json'
)
```

**Cell 2 — Sink Table (alerts output):**
```sql
%flink.ssql
CREATE TABLE ecomm_alerts_sink (
    user_id VARCHAR,
    event_count BIGINT,
    window_start TIMESTAMP(3),
    window_end TIMESTAMP(3)
)
WITH (
    'connector' = 'kinesis',
    'stream' = 'ecomm-alerts-stream',
    'aws.region' = 'us-east-1',
    'format' = 'json'
)
```

**Cell 3 — Anomaly Detection INSERT (run this last, keeps running):**
```sql
%flink.ssql
INSERT INTO ecomm_alerts_sink
SELECT
    user_id,
    COUNT(*) AS event_count,
    TUMBLE_START(event_arrival_time, INTERVAL '1' MINUTE) AS window_start,
    TUMBLE_END(event_arrival_time, INTERVAL '1' MINUTE) AS window_end
FROM ecomm_events
GROUP BY
    user_id,
    TUMBLE(event_arrival_time, INTERVAL '1' MINUTE)
HAVING COUNT(*) > 5
```
